## 视觉与交互

复用原有色彩、字号、空间、胶囊导航、页面容器、内容入场、lightbox 和视频组件。新增共享变量：亚克力板厚度、边缘与反光、阴影、画廊相机、右移距离、项目首屏字号、首屏遮罩及 720ms 项目转场。没有新增依赖。

首页按用户截图改成左下至右上的单列纵深队列，21 个位置重复展示七个项目，在视口外回收位置；仅中央一组七张参与键盘顺序。保留黑色背景留白，滚动时队列不会出现断档。卡片在统一相机下投影为竖直的 Y/Z 平面，沿 X 轴排列。相机位置 [-5.9, 3, 3.4]、视角 15°，复用参考站的空间关系；使用原生 CSS matrix3d，无新增依赖。悬停沿展板的世界 Z 轴移动 0.65 单位，向右抽出并停留，白色项目名和类别跟随指针显示，保留薄亚克力侧边。手机支持横向或纵向拖动。

点击站内页面时，黄色幕布从下方覆盖整个视口；高度为 100dvh，新页面立即向上揭开，无额外停留，再露出主视觉、标题与概述。浏览器前进后退和缓存恢复同样使用上拉揭幕。点击项目进入全屏主视觉、居中标题与概述；章节导航提供概述、影片、制作流程、成果和画廊入口。下一项目缩略图和图片档案保留原比例。全屏首图为等比裁切，提供完整画幅查看入口。

### 竖直卡片与轻量转场更新

每次返回首页（含浏览器历史恢复）触发 650ms 的画廊入场，从右上方向沿队列推进至左下；操作滚轮或触摸时可立即完成入场。星形首页按钮点击旋转 360°，时长 540ms；首页原地点击也会重播入场。透明气泡的 DOM、样式及监听已删除，保留原生鼠标、白色项目标题和轨迹烟花。黄色幕布恢复 100dvh 全屏覆盖，点击项目后用 90ms 覆盖视口；新文档解析时由 CSS 立即揭幕，不等待脚本或图片，0ms 停顿并以 150ms 向上揭开；主图与标题在约 180ms 内进入。所有新动画遵循减少动态效果设置。
