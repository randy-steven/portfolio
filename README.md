# 冯嘉韵 · 影像与空间作品集

从零建立的静态作品集，包含首页、作品索引、七个项目详情、关于、联系、完整作品册与 404 页面。源内容来自 `D:/GAFA/网站作品集/`，原文档、图片、视频及 PDF 均未改动。

## 内容维护

- `content/portfolio.json`：个人资料、项目简介、个人职责、创作过程与工具。
- `content/网站文案.md`：适合网页阅读的改写稿，由构建脚本生成。
- `content/editorial-notes.md`：逐项目的来源与删改记录，包括移除的未确认表述。
- `content/media.json`：108 张原图与网页图片的映射。
- `content/videos.json`：7 段完整视频的路径、时长与显示比例。
- `scripts/build.mjs`：页面模板、项目顺序、精选封面、PDF 对应页码。
- `dist/styles.css`：共享设计变量与页面样式；`dist/app.js`：导航、画廊、筛选和联系；`dist/media.js`：大图与视频。

内容编辑后运行 `npm run build`；样式和交互文件直接编辑。运行 `npm run dev`，浏览器访问终端输出的本地地址。项目不需要安装构建依赖。`npm run check` 检查脚本语法、所有本地链接、遗留占位内容及单文件大小。

## 文案与素材

七个项目为：后西游记、吴晓波科技人文秀《觉醒》《虚拟圆桌》、ODYSSEY｜启、无界之海、台湾岛纪、CO-EVO、傩屿·织械创生。文案保留项目背景、个人参与范围与制作方法，删除内部写作提示、待核实草稿、重复自评、与本人职责不直接对应的传播数据。资料中未给出的日期、工具和奖项不补写。

108 张作品图片全部进入详情页，缩略图用于浏览，详情保留原始比例；超宽图跨栏展示，可放大。作品册 36 页全部可阅读，并提供原版 PDF 下载。关于页照片来自作品册，邮箱来自个人简历。目前没有需要替换的虚构项目或视觉占位。后西游记参与日期尚未提供，当前隐藏；制作流程已按更新资料补充 Seedance 2.0。

5 段短视频使用 MP4，2 部长片使用 HLS 分段播放。所有视频保留完整时长与音轨，点击才加载；长片网络版为 960 像素宽，较原片有所压缩，原片仍在素材文件夹。HLS 播放器使用本地托管的 hls.js 1.7.3（Apache-2.0，许可证随文件提供），因为静态项目没有现成的跨浏览器 HLS 播放能力。没有第三方字体、分析追踪或自动发送表单；联系表单生成邮件草稿和文字文件，由访客确认发送。

## 设计系统

项目从零建立，没有原有框架、UI 库或动画库。先建立 CSS 变量，再共用导航胶囊、页面容器、双栏内容区、项目卡片、筛选按钮、一次性入场、图片预览、视频容器与作品册入口。

主要变量：`--color-bg` #090909、`--color-fg` #f4f3ee、`--color-muted` #9b9b95、`--color-accent` #dafa45；系统无衬线 Arial / Helvetica Neue / 苹方 / 微软雅黑。空间基准为 4、8、12、16、24、32、48、64、96、128、176px；移动端调整大间距。容器最大 1600px，页边距 20–64px，胶囊半径 100px，触控最小 44px。字号、行高、字距、层级、阴影、透视、角度、时长和缓动均集中管理。

实际内容接入时补充 `--text-project-cn`、`--text-caption`、`--media-gap`、`--color-overlay`、`--book-width`、`--delay-menu`；沿用首版的 `.pill`、`.page-main`、`.section-grid`、`.work-card`、`.filter`、`.reveal` 与色彩/间距变量。

## 动效

| 触发 | 变化 | 时长 / 延迟 / 缓动 |
|---|---|---|
| 首页加载 | 画廊 translate + opacity | 2000ms；200ms 起，逐卡 70ms；(.65,0,.35,1) |
| 首页加载 | 标题 translateY + opacity | 800ms；延迟 500ms；(.65,0,.35,1) |
| 滚轮 / 拖拽 | 画廊整体平移 | 每帧插值 0.1，范围覆盖全部 7 张卡；无自动轮播 |
| 卡片悬停 | translateZ / translateY + brightness | 进入 500ms，离开 350ms；(.65,0,.35,1) |
| 胶囊导航悬停 / 键盘焦点 | 双文字层纵向位移 | 450ms；(.68,-.6,.32,1.6) |
| 索引卡片悬停 | 图片 scale 1→1.035、箭头平移 | 500ms；(.65,0,.35,1) |
| 内容进入视口 | opacity + translateY | 800ms；(.65,0,.35,1)；仅一次 |
| 打开手机菜单 | 面板 translateY | 1200ms；(.87,0,.13,1) |
| 菜单链接进入 | opacity + translateY | 400ms；800ms 后逐项间隔 70ms |
| 自定义查看光标 | 跟随 pointer + opacity | 淡入/淡出 350ms，仅精确指针设备 |

仅动画 transform、opacity 与 filter。`prefers-reduced-motion` 禁用动画和拖动画廊，键盘仍可居中访问作品。原生链接提供完整浏览路径；禁用 JavaScript 时内容和备用导航仍可访问。原生 dialog 支持 Escape 关闭、焦点返回与焦点圈。

## 参考研究与差异

参考 Gabriel Veres 首页的单屏空间画廊、黑底、大留白、斜向层叠图片、胶囊导航与荧光色菜单。真实 CSS、脚本及交互研究见 `content/reference-audit.md`；参考截图与下载图仅保留在系统临时文件夹，没有进入网站。

本网站用 DOM + CSS 透视构成画廊，参考站使用 WebGL、无限循环和图像着色器；本网站的画廊有边界，提供作品索引。为中文内容使用系统字体，没有复制参考品牌、字体文件、文案或图片。没有复制参考站的路由裁切、音频文件及 blog；鼠标轨迹、烟花和合成音效按本项目需求重新实现；作品册取代无内容支持的 blog。详情页按自己的影像与超宽图比例组织，没有强行裁成参考站的网页设计截图。

## 验证与交付

本地 Edge 实机渲染检查覆盖 1440、768、390、360px；验证菜单、Escape 与焦点返回、作品筛选、图片切换、邮件草稿、7 段视频播放、无 JavaScript 导航及减少动态效果。网页自动检查与截图保留在忽略提交的 `review/`。项目图片、原作品册与本地视频由本站托管；台湾岛纪由 Bilibili 官方提供。图片懒加载，视频按需加载。

网站使用 Sites 发布，站点 ID 保存在 `.openai/hosting.json`，保持创建时的仅本人可访问权限。后续编辑沿用同一站点。部署状态与最终 URL 以实际发布结果为准。
